# 第一次之后的推送

cd 进入已有的仓库目录

git pull                    # 1. 拉取最新代码（获取别人可能的修改）

修改 main.cpp...            # 2. 用编辑器修改文件

git add main.cpp            # 3. 暂存修改

git commit -m "说明"        # 4. 提交到本地

git push                    # 5. 推送到 GitHub，第一次推送时，本地 main 分支还没有关联到远程的 main 分支，Git 不知道它们之间的关系，所以必须明确指定
